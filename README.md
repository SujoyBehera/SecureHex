#  SecureHex

SecureHex is a Java-based Secure Credential Management System that I am building while learning Java and Object-Oriented Programming.

##  Current Features

- User Registration
- User Login
- Input Validation
- Email Normalization (trim + lowercase)
- Basic Credential Management

##  Tech Stack

- Java
- IntelliJ IDEA
- Git
- GitHub

##  Planned Features

- Logical Operators
- Switch Menu
- Loops
- Methods
- Arrays
- Object-Oriented Programming
- Swing GUI
- JDBC
- MySQL
- Password Generator
- Password Strength Checker
